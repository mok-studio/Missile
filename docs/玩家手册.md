# Missile 玩家手册

简体中文 | [English](Player-Manual.md)

**主手拿 TNT → 右键（开导引头、锁定）→ 再右键（发射）。** TNT 就是弹药：生存模式每发消耗 1 个，创造模式不消耗。

服主 / 开发请看仓库根目录的 [README.zh-CN.md](../README.zh-CN.md)（构建、配置、命令与权限、占位符）。

## 1. 操作与锁定

| 步骤 | 动作 | 屏幕反馈 |
|---|---|---|
| 1 | `/msl ir` / `/msl semi` / `/msl active` / `/msl semiLOS` 选型号 | 聊天栏显示型号与参数 |
| 2 | **主手**持 TNT，**右键** | 动作栏 `§f§k1 §7红外导弹 §7\| §f目标: 任意 §7\| §a锁定 §fSteve §7\| §f按右键发射 §f§k1` |
| 3 | **再右键** | 动作栏显示"已发射"，导弹出膛，消耗 1 个 TNT |

- **锁定判定**：准星 **10° 锥角**内、**128 格**内、视线不被方块挡住、且不是你自己；多个候选取**距离最近者**，开导引头后每 **2 tick** 刷新一次。
- 主手换掉 TNT 立刻关闭导引头；开着导引头时右键**不会**放置 TNT 方块。
- 锁定时动作栏**两端各有一段 `&f&k` 乱码**（与正文之间各留 1 个空格），这是"已锁定"的标记；没锁上不会出现。
- 动作栏的「**目标**」= 你实际能锁什么：`玩家` / `实体` / `混合`（两类都允许）/ `任意`（名单里没有具体目标）。超级主动弹按它自己的 safilter 名单内容判断，实体与玩家条目都有则显示 `混合`。
- **半主动雷达**没有合法目标时**拒绝发射**；**semiLOS** 不锁目标，跟着准星前方 200 格的点飞。

## 2. 五种导弹

| | 红外 `ir` | 半主动 `semi` | 主动 `active` | 半自动指令瞄准线 `semiLOS` | 超级主动弹 `super_active` |
|---|---|---|---|---|---|
| 谁能用 | 所有人 | 所有人 | 所有人 | 所有人 | **仅管理员** |
| 初速 → 最高速 | 5 → 25 m/s | 5.2 → 30 m/s | 6 → 40 m/s | 5.2 → 30 m/s | **8 → 850 m/s** |
| 灵活度（转弯） | 中（6°/tick） | 低（4°/tick） | 高（7°/tick） | 很高（12°/tick） | **极高（30°/tick）** |
| 爆炸威力 | 3.0 | 3.5 | **4.5**（接近 TNT） | 3.5 | **10.0** |
| 发射后要一直盯着吗 | 不用（自动追） | **要**（持续照射） | 不用（自动追、会算提前量） | **要**（用准星"驾"着飞） | 不用 |
| 打提前量 | 无（直追） | 无 | **有**（算你的移动） | —— | **有** |
| 目标躲掩体后 | 55 格 / 30° 内重新抓 | 失去照射就直飞，重新看向可恢复 | 记 5 秒最后位置，3 秒后 70 格 / 40° 自己重抓 | —— | 记 5 秒，3 秒后 **100 格 / 45°** 重抓 |
| 干扰物 | **烈焰粉**（丢出，15%/秒） | 铁粒（5%/秒，**永久断链**） | 铁粒（2.5%/秒，3 秒后自己重抓） | **无干扰物** | **完全免疫干扰** |
| 会触发对方 RWR 吗 | **不会** | 会（跟踪 + 导弹两级） | 会（跟踪 + 导弹两级） | **不会** | **会** |
| 会触发对方 MAWS 吗 | 会（40 格内） | 会 | 会 | 会 | 会 |
| 尾焰颜色 | 橙红 | 淡橙 | 青铜色 | 青蓝色 | 青铜色 |

表里是服务器出厂默认值；服主可在 `msl_config.yml` 改任意一项（改完 `/msl reload` 生效），实际以 `/msl status` 显示的为准。

## 3. 怎么选

- **红外** —— 偷袭首选：不触发对方 RWR，从背后发射毫无提示（但 40 格内会触发 MAWS，别贴太近）。缺点：对方丢烈焰粉时 15%/秒被拽走，转弯一般。
- **半主动雷达** —— 高处 / 远距离、能稳定看着目标时用；可中途改锁（准星换人，导弹跟着换）。被铁粒干扰一次就**永久断链**，转弯最笨，别用来打贴脸绕圈的对手。
- **主动雷达** —— 综合最强：快、灵活、抗干扰最好、会算提前量、威力大；代价是对方 RWR 会清楚报警。
- **半自动指令瞄准线（semiLOS）** —— 手动驾束：准星指哪它飞哪。不触发 RWR、免疫一切干扰物，但没有近炸引信（只在直接命中时爆炸），且你必须一直在同一维度活着——你死了 / 换维度 / 下线，它就沿最后方向直飞。
- **超级主动弹** —— 仅管理员可用；又快又灵活、威力 10、免疫干扰，会触发对方全部告警。

## 4. 反制与自保

### 干扰物（必须**丢出去**才生效）

| 干扰物 | 克制型号 | 每秒脱锁概率 | 平均生效时间 | 附加条件 |
|---|---|---|---|---|
| **烈焰粉** | 红外 | 15% | 约 7 秒 | 丢出后 **3 秒**内有效；导弹在 **48 格**内，且**你在导弹前方** |
| **铁粒** | 半主动雷达 | 5% | 约 20 秒 | 同上 |
| **铁粒** | 主动雷达 | 2.5% | 约 40 秒 | 同上，而且它 3 秒后会自己重新抓你 |

- **拿在手上不算**：必须用"丢弃物品"键丢出去，掉落物在地上的 3 秒内有效；发射者本人丢的对自己没用。
- **烈焰粉对红外是"拉走"**：导弹脱锁并转而追踪**那件掉落的烈焰粉**，5 秒内不会重新锁回丢粉的人——队友丢烈焰粉可以替你把红外弹引开。
- **红外不吃铁粒；semiLOS 与超级主动弹不吃任何干扰物。**

### 靠地形

- **红外 / 主动 / 超主动**的弹上导引头**不看方块遮挡**，只要目标还在它前方锥角内就会重新抓住；它们都有 **3 格近炸引信**，擦边就爆。
- **半主动**依赖发射者视线：**躲进掩体就断照射**（导弹直飞），对方重新看向你就能恢复。
- **主动 / 超主动**会算你的移动方向打提前量 —— 直线逃跑最容易被命中，**频繁变向**更有效。

## 5. 被打时怎么知道：RWR 与 MAWS

**开机条件（三条都要满足，否则收不到任何告警）**：

1. 有 `missile.use` 权限（默认人人都有；管理员有 `missile.admin` 也行）；
2. **你自己**用 `/msl on` 开着导弹模式（`/msl off` 一关，立刻静默）；
3. 背包里（任意槽位）放一个**指南针**。

取出指南针或自己 `/msl off`，告警立即消失。

| 告警 | 触发时机 | 显示 | 声音 |
|---|---|---|---|
| **RWR 敌跟踪** | 有人开着半主动 / 主动导引头、锁定的是你（**还没发射**） | **黄色** BossBar `⚠ 敌跟踪 →` | 高 / 低音**交替**，每 **0.2 秒** |
| **RWR 敌导弹** | 已有半主动 / 主动导弹在飞、锁定目标是你 | **红色** BossBar `⚠ 敌导弹 ↘ ×2` | **急促**高音，每 **0.1 秒** |
| **MAWS** | **40 格**内有东西**正朝你逼近**（接近率 > 10 m/s）：**箭 / 光灵箭 / 三叉戟 / 任何导弹**（含红外、semiLOS） | **红色** BossBar `⚠ MAWS: ↑` | 默认无声（服主可开） |

- **MAWS 与 RWR 是两条独立的条，可以同时出现**；RWR 多个威胁时显示**最近那个**并附 `×数量`，敌导弹优先于敌跟踪。
- MAWS 只报**正在逼近**的东西，**你自己刚射出去的箭 / 导弹不会报自己**；别人的箭朝你飞来照样会报。
- **方位以你当前朝向为正前方（↑）**，顺时针 8 档：`↑` 正前 / `↗` 右前 / `→` 正右 / `↘` 右后 / `↓` 正后 / `↙` 左后 / `←` 正左 / `↖` 左前（12点钟 / 1:30 / 3点钟 / 4:30 / 6点钟 / 7:30 / 9点钟 / 10:30）。
- 读法举例：`⚠ 敌导弹 ↓` = 导弹正在你正后方追来；`⚠ 敌跟踪 ↖` = 左前方有人用雷达盯着你；`⚠ MAWS: ↗` = 右前方 40 格内有一发导弹（可能冲别人去的）。
- **红外导弹与 semiLOS 永远不会触发 RWR**，但 **MAWS 会** —— "没有 RWR 告警"不等于安全。RWR 告警范围上限 256 格（服主可调）；死亡 / 重生 / 退出会清掉告警条。

## 6. 命令速查

| 命令 | 说明 |
|---|---|
| `/msl`、`/msl status` | 型号与参数、目标类型、导引头、个人/全服开关、IR 模式、SA 锁定类型、筛选模式 |
| `/msl ir` | 红外导弹（不加参数时**不改动**已设的模式） |
| `/msl ir player` / `entity` / `default` | 红外工作模式：只锁玩家 / 丢失玩家后转任意实体 / 恢复默认 |
| `/msl ir usefilter` / `filteroff` | 开 / 关白名单通道（只按 `/msl filter list` 的白名单挑目标） |
| `/msl semi` / `active` / `semiLOS` | 半主动 / 主动 / 半自动指令瞄准线 |
| `/msl on` / `off` | **你自己的**导弹开关（默认开）。`off` 后手持 TNT 恢复原版，**同时收不到 RWR/MAWS 告警** |
| `/msl default` | 一键恢复默认：IR 模式、usefilter、SA 模式与 safilter、导引头、**目标筛选白名单**；**型号与 `on\|off` 保留** |
| `/msl filter ...` | 目标筛选（见下） |
| `/msl super_active [default\|entity\|player]` | 超级主动弹（**仅管理员**） |
| `/msl super_active entity\|player <set\|add\|remove\|clear> [值...]` | 编辑 safilter 条目（**仅管理员**，见下） |
| `/msl global on\|off`、`/msl reload` | 全服开关、热重载配置（**仅管理员**） |

- 别名 `/msl` ≡ `/missile`；型号还接受 `infrared` / `sarh` / `arh` / `semilos` / `los` / `line` / `红外` / `半主动` / `主动` / `指令` / `驾束` / `线导` / `1` `2` `3` `4` `5`。
- 参数写错不会报错：**从左往右解析，遇到第一个非法参数就停下**，只执行它前面那部分（`/msl ir player 114514` = `/msl ir player`）。例外是 `remove`：写了"合法但名单里没有"的条目只会列出来，不中断。

### `/msl default`：把设置清干净

| 会重置 | 会保留 |
|---|---|
| `/msl ir` 设的模式、`usefilter` 开关 | **你选的型号**（红外 / 半主动 / 主动 / semiLOS / 超级主动弹） |
| 超级主动弹的模式与 **safilter** | **`/msl on` / `/msl off` 开关** |
| 导引头（立即关闭） | 别人的任何设置、全服开关 |
| **目标筛选白名单 + 筛选模式**（`/msl filter` 的全部数据） | —— |

只想清筛选、不动其它设置时，用 `/msl filter clear`。

### 目标筛选（白名单）

| 命令 | 效果 |
|---|---|
| `/msl filter entity zombie skeleton` | 只锁僵尸和骷髅（写 `minecraft:zombie` 也行） |
| `/msl filter entity` | 允许"任意生物"（不指定 ID） |
| `/msl filter entity oak_boat` | **可以打船了**：载具 / 末地水晶 / 盔甲架等默认锁不上，**显式写出它的 ID** 才解锁 |
| `/msl filter entity boat` | 组别名 = 所有船（含各种木材与 chest 变体）；`minecarts` 同理 |
| `/msl filter player Steve` | 只锁 Steve（玩家名必须是**在线**的） |
| `/msl filter player` | 允许所有玩家 |
| `/msl filter entity add zombie` | 在已有白名单上**追加**（`set` 则是先清空全部再写） |
| `/msl filter entity remove zombie` | **把已添加的僵尸摘掉**（只动这一条） |
| `/msl filter player remove Steve` | 把 Steve 从玩家名单里摘掉（**离线也能删**） |
| `/msl filter entity clear` / `player clear` | 只清掉某一类 |
| `/msl filter list` | 查看当前模式与白名单明细 |
| `/msl filter on` / `off` | 启用 / 停用筛选模式（`off` = 自由锁定，白名单保留） |
| `/msl filter clear` | 清空全部筛选数据（不动 `on`/`off`） |

- 白名单是**"只允许名单内"**模型：玩家名单为空 = 允许所有玩家；实体类里有 ID 就只认这些 ID。
- 写入类型或 ID 会**自动把筛选模式置为 on**；**筛选模式开着但白名单为空 = 什么都锁不上**，所以空白名单时 `/msl filter on` 会被拒绝，清空白名单时会自动关回 `off`。
- `set` / `add` / `remove` 后面必须跟 ID，否则整条命令无效（不会误清空）。
- **`remove` 只删条目、没有副作用**：不会顺手打开某一类、也不改筛选模式；把某一类删空就等于回到"这一类不限制"。**按 Tab 会列出名单里已有的条目**。
- 筛选数据**保存在服务器上**（默认 `plugins/Missile/data/filters.json`），重启后仍在。
- **筛选模式打开时，能锁哪一类由白名单决定**：`/msl filter entity add phantom` 之后（即使型号是只锁玩家的红外默认模式）**幻翼就能锁上了**；玩家类没启用时玩家仍不可锁。筛选关掉才回到 `/msl ir` 的锁定类型。

### 超级主动弹的 safilter（仅管理员）

一套**独立名单**，与 `/msl filter` 互不影响，而且**退出登录就回默认**：

| 命令 | 效果 |
|---|---|
| `/msl super_active default` | 任意目标（并清空 safilter） |
| `/msl super_active entity` / `player` | 只锁生物 / 只锁玩家（并清空 safilter） |
| `/msl super_active entity add zombie` | 实体类名单**追加**僵尸（`add` 可简写成直接写 ID） |
| `/msl super_active entity set zombie skeleton` | 实体类名单**设为**这两项（覆盖原来的实体类条目） |
| `/msl super_active entity remove zombie` | 实体类名单**摘掉**僵尸 |
| `/msl super_active entity clear` / `player clear` | 清空该类（另一类保留） |
| `/msl super_active filter list` | 查看 safilter 的模式与明细 |

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 右键把 TNT 放地上了 | 你自己 `/msl off` 关过导弹系统（`/msl on` 恢复） |
| 右键没反应 | 没拿**主手** TNT；或没有 `missile.use` 权限 |
| 半主动弹发射不了 | 准星锥内没有合法目标（或视线被挡、白名单为空）—— 先看向目标再右键 |
| 锁不上人 | 超过 128 格 / 不在准星 10° 内 / 视线被方块挡住 / 对方是旁观者 / 白名单里没有他 |
| 锁不上船、矿车、末地水晶 | 载具等非生物**默认锁不上**：`/msl filter entity set boat`（或 `oak_boat`、`minecart`）显式列出后才能锁 |
| 白名单加了 `phantom` 却连幻翼都锁不上 | 已修：筛选模式打开时以白名单启用的类别为准 |
| `/msl filter on` 提示"白名单是空的" | 故意的：空白名单 + 筛选模式 = 什么都锁不上，先去 `/msl filter entity <ID>` 写点东西 |
| 开了 usefilter 后什么都锁不上 | `/msl filter list` 看白名单是不是空的；`/msl ir filteroff` 关掉 |
| 导弹中途拐弯、追别人去了 | 附近有人丢出干扰物：红外被烈焰粉拉走，半主动 / 主动被铁粒干扰 |
| 导弹直飞不追 | 用的是 `semiLOS`（本来就是手动驾束）；或目标已死 / 前方无目标 |
| 导弹没直接命中也炸了 | 红外 / 半主动 / 主动 / 超主动都有 **3 格近炸引信**（semiLOS 例外） |
| 自己被炸伤 / 地形被炸 | 爆炸会伤及自身，发射后别贴脸；地形破坏由服主的 `explosion.break-blocks` 决定 |
| 完全没有告警 | 要同时满足：有权限 + 自己 `/msl on` + 背包里有**指南针**；另外红外与 semiLOS 本来就不触发 RWR |
| 有 RWR 但没 MAWS（或反之） | MAWS 只认 **40 格**距离、且服主可整体关掉（`maws.enabled`） |
| 提示文案是英文 | 服主把 `language` 设成 `en_us` 了，可请他切回 `zh_cn` |
| 动作栏 / 告警条突然消失 | 主手换掉了 TNT（导引头关闭）；或威胁解除；或你自己 `/msl off` 了 |
| 动作栏文字两端出现乱码 | 那是"已锁定"的标记（`launcher.lock-padding`），两侧与正文各隔 1 个空格；没锁上就不会出现 |
| 想把设置全部清空重来 | `/msl default`：重置 IR 模式 / usefilter / SA 模式与 safilter / 导引头 / 筛选白名单；**型号与 `/msl on\|off` 保留** |
| 名单里加错了条目想删掉 | `/msl filter entity\|player remove <ID>`（按 Tab 会列出已有条目）；safilter 用 `/msl super_active entity\|player remove <值>` |

## 8. 十条实用技巧

1. **偷袭用红外**：不触发 RWR；但别贴到 40 格内，否则对方 MAWS 会亮起来。
2. **正面冲突用主动**：速度快、会打提前量、抗铁粒最好。
3. **对方丢烈焰粉克制你的红外时，换 semiLOS** —— 它免疫全部干扰物。
4. **半主动可以中途换目标**：准星移到另一个人身上，导弹跟着改锁，适合打乱阵型。
5. **别忘了这是"视线"武器**：开导引头时目标必须在准星锥内且**没被方块挡住**。
6. **主动弹打逃跑的人是直线最优**：逃跑时**变向**比加速更保命。
7. **导弹擦边也会炸**（3 格引信），躲的时候留余量。
8. **听到"敌跟踪"就断视线**：半主动的照射需要视线，躲进掩体就能让它直飞。
9. **听到"敌导弹"马上丢干扰物**：烈焰粉克红外、铁粒克半主动 / 主动，且要让导弹在你**前方**才生效（拿在手上没用）。
10. **`/msl ir entity` 是打怪神技**：丢失玩家后自动转去锁任意生物；想反过来只打玩家就用 `default`。

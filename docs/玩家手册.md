# Missile 玩家手册

> 面向玩家：怎么拿、怎么锁、怎么打、怎么躲。
> 服主 / 开发者请看 [README.md](README.md)（安装、构建、配置、API 说明）。

---

## 1. 一句话上手

**主手拿 TNT → 右键（开导引头、锁定）→ 再右键（发射）。**

TNT 就是弹药：生存模式每次发射消耗 1 个，创造模式不消耗。

## 2. 操作三步

| 步骤 | 动作 | 屏幕反馈 |
|---|---|---|
| 1 | `/missile <型号> <player\|entity>` 选型号与锁定对象（可省略，默认红外 + 锁玩家） | 聊天栏提示当前型号与参数 |
| 2 | **主手**持 TNT，**右键** | 动作栏出现状态：`红外导弹 \| 目标:玩家 \| 锁定 Steve \| 再右键发射` |
| 3 | **再右键** | 动作栏提示 `发射 …`，导弹出膛，消耗 1 个 TNT |

细节：

- 开导引头后，**每 2 tick 自动刷新锁定**（准星附近的目标变了会自动切到最近的那个）。
- **主手换掉 TNT，导引头立刻关闭**（动作栏提示“需要手持 TNT”）。
- 开着导引头时右键**不会**放置 TNT 方块，只用于导引头。
- 锁定判定：准星 **10° 锥角**内、**128 格**内、**视线不被方块挡住**、且不是你自己 —— 多个候选时取**距离最近者**。
- 锁定对象由命令第 2 个参数决定：`player` 只锁玩家，`entity` 只锁生物（怪物 / 动物 / 村民等，**不含玩家**）。

## 3. 四种导弹（玩家视角）

| | 红外 | 半主动雷达 | 主动雷达 | 半自动指令瞄准线 |
|---|---|---|---|---|
| 命令参数 | `ir` | `semi` | `active` | `semiLOS` |
| 初速 → 最高速 | 5 → 25 m/s | 5.2 → 30 m/s | 6 → 40 m/s | 5.2 → 30 m/s |
| 灵活度（转弯） | 中（6°/tick） | 低（4°/tick） | 高（7°/tick） | 很高（12°/tick） |
| 爆炸威力 | 3.0 | 3.5 | **4.5**（接近 TNT） | 3.5 |
| 发射后要一直盯着目标吗 | 不用（自动追） | **要**（必须持续看着） | 不用（自动追） | **要**（要用准星“驾着”飞） |
| 打提前量 | 无（直追屁股） | 无 | **有**（会算你的移动） | —— |
| 目标躲进掩体后 | 丢掉后 55 格 / 30° 内重新抓 | 失去照射就直飞，重新看向可恢复 | 记 5 秒最后位置，脱锁后 70 格 / 40° 内自己重抓 | —— |
| 干扰物 | **烈焰棒**（15%/秒） | 铁粒（5%/秒，**永久断链**） | 铁粒（2.5%/秒，3 秒后自己重抓） | **无干扰物** |
| 会触发敌方 RWR 告警吗 | **不会** | 会（跟踪 + 发射两级） | 会（跟踪 + 发射两级） | **不会** |
| 尾焰颜色 | 橙红 | 淡橙 | 青铜色 | 青蓝色 |

**无锁定也能发射的型号**：红外、主动雷达（出膛后自己找目标）；半自动指令瞄准线不需要锁定（靠准星驾束）。
**只有半主动雷达**在“准星里没有合法目标”时会**拒绝发射**并提示。

## 4. 怎么选（实战建议）

- **红外** —— 偷袭首选。**不会触发对方的 RWR 告警**，从背后发射对方毫无提示。缺点：对方手上有烈焰棒时 15%/秒被拽走（平均约 7 秒脱锁），而且转弯一般。
- **半主动雷达** —— 你在高处 / 远距离、能稳定看着目标时用。可以中途改锁（准星换人，导弹跟着换），但**被铁粒打 5% 就永久断链**（平均约 20 秒），转弯也最笨，别用来打贴脸绕圈的对手。
- **主动雷达** —— 综合最强：最快（40 m/s）、最灵活、抗干扰最好（2.5%/秒，平均约 40 秒）、会算提前量、威力最大。代价是**对方 RWR 会清楚报警**，且你能看见对方开始机动躲你。
- **半自动指令瞄准线（semiLOS）** —— 手动驾束：**你准星指哪它飞哪**（视线前方 200 格处的瞄点，被方块挡住时取命中点）。**不触发敌方 RWR、免疫一切干扰物**，但转弯受 12°/tick 限制，**没有近炸引信（只在直接命中时爆炸）**，且**你必须一直在同一维度活着**——你死了 / 换维度 / 下线，它就沿最后方向直飞。适合中近距精确点名、或者对方拿干扰物恶心你时换它。

## 5. 反制与自保

### 干扰物（拿在**主手或副手**即生效）

| 干扰物 | 有效型号 | 每秒脱锁概率 | 平均生效时间 | 附加条件 |
|---|---|---|---|---|
| **烈焰棒** | 红外 | 15% | 约 7 秒 | 导弹在 **48 格**内，且**你在导弹导引头的前方**（导弹朝你飞来时即可） |
| **铁粒** | 半主动雷达 | 5% | 约 20 秒 | 同上 |
| **铁粒** | 主动雷达 | 2.5% | 约 40 秒 | 同上，且只是 3 秒后它自己会重新抓你 |

- 干扰物每秒判定一次，**拿在手上就一直生效**；发射者本人的干扰物无效。
- **烈焰棒对红外是“拉走”**：导弹会脱锁并转而追踪举烈焰棒的人 —— 所以队友举烈焰棒可以替你把红外弹引开。
- **红外不吃铁粒；半主动指令瞄准线不吃任何干扰物。**

### 靠地形

- **红外 / 主动**的弹上导引头**不看方块遮挡**，只要目标还在它前方锥角内（55 格 / 30°、70 格 / 40°），躲进掩体也会被重新抓住 —— 而且它**有 3 格近炸引信**，擦边就爆。
- **半主动**依赖发射者的视线：**躲进掩体就断照射**（导弹直飞），但对方重新看向你就能恢复。
- **主动**会算你的移动方向打提前量 —— 直线逃跑最容易被命中，**频繁变向**更有效。

## 6. RWR 雷达告警（被锁定时怎么知道）

**开机条件：背包里（任意槽位）放一个指南针（COMPASS）**，取出就静默。

| 告警 | 触发时机 | 显示 | 声音 |
|---|---|---|---|
| **敌跟踪** | 有人开着半主动 / 主动导引头、锁定的是你（**还没发射**） | 黄色 BossBar：`⚠ 敌跟踪 →`（威胁在你正右） | 高音 / 低音**交替**，每 1 秒一次 |
| **敌导弹** | 已有半主动 / 主动导弹在飞、锁定目标是你 | 红色 BossBar：`⚠ 敌导弹 ↘ ×2`（两发，最近那发在右前方） | **急促**高音，每 0.25 秒一次 |

- **方位用箭头表示，以你当前朝向为正前方（↑）**，顺时针 8 档：`↑` 正前 / `↗` 右前 / `→` 正右 / `↘` 右后 / `↓` 正后 / `↙` 左后 / `←` 正左 / `↖` 左前（对应传统写法的 12点钟 / 1:30 / 3点钟 / 4:30 / 6点钟 / 7:30 / 9点钟 / 10:30）。
- 多个威胁时显示**最近那个**的方位，并在后面附 `×数量`；敌导弹优先于敌跟踪；威胁消失告警自动消失。
- **红外导弹与半自动指令瞄准线永远不会触发你的 RWR** —— 所以“没有告警”不等于安全。
- 告警范围上限 256 格；死亡 / 重生 / 退出会清掉告警条。

```
                ↑（正前）
       ↖                       ↗
  ←（正左）       你        →（正右）
       ↙                       ↘
                ↓（正后）
```

读法举例：听到急促音 + `⚠ 敌导弹 ↓` = **导弹正在你正后方追来**，该做机动或抛干扰物了；`⚠ 敌跟踪 ↖` 则是有人在**左前方**用雷达盯着你。

## 7. 命令速查

| 命令 | 说明 |
|---|---|
| `/missile` | 等价 `/missile ir player`：红外 + 锁玩家 |
| `/missile ir` | 红外，锁定对象默认玩家 |
| `/missile semi` / `/missile active` | 半主动 / 主动雷达 |
| `/missile semiLOS` | 半自动指令瞄准线 |
| `/missile active entity` | 主动雷达，锁**生物**（打怪 / 打村民） |
| `/missile on` / `/missile off` | **你自己的**导弹开关（默认开）。`off` 后你手持 TNT 恢复原版：可以正常放置 TNT；别人不受影响 |
| `/missile filter ...` | 目标筛选（见下方「目标筛选」一节） |
| `/missile status` | 查看当前型号、锁定对象类型、速度、干扰物与脱锁概率、导引头与锁定状态 |

别名 `/msl`。型号还接受 `infrared` / `sarh` / `semi-active` / `arh` / `semilos` / `los` / `line` / `红外` / `半主动` / `主动` / `指令` / `驾束` / `线导` / `1` `2` `3` `4`；
锁定对象还接受 `p` / `mob` / `mobs` / `玩家` / `生物` / `实体`。

需要权限 `missile.use`（默认所有人都有）。

### 目标筛选（可选）

想让导引头只锁某类目标？用 `/missile filter ...`（也可写 `/msl filter ...`）：

| 命令 | 效果 |
|---|---|
| `/missile filter entity` | 只锁**生物**（不含玩家） |
| `/missile filter player` | 只锁**玩家** |
| `/missile filter !player` | **不锁玩家**，其他目标照锁 |
| `/missile filter zombie` | 只锁僵尸 |
| `/missile filter !creeper` | 不锁苦力怕 |
| `/missile filter entity zombie !creeper` | 锁生物、包含僵尸、排除苦力怕 |
| `/missile filter list` | 看当前筛选配置 |
| `/missile filter all` | 回到**自由锁定**（筛选列表会保留，方便以后再启用） |
| `/missile filter clear` | 清空筛选列表，回到自由锁定 |

要点：**排除项优先**、**包含项之间是「或」**；只写排除项（如 `!player`）时其余目标照样能锁；实体 ID 可写 `zombie` 或 `minecraft:zombie`（写错会报错）；`entity` 和 `player` 不能同时用；筛选条件会**累加**（想重来就 `clear`）。筛选只影响你自己，服务器重启后清空。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 右键把 TNT 放地上了 | 你自己用 `/missile off` 关过导弹系统，此时你的 TNT 是原版物品（`/missile on` 恢复） |
| 右键没反应 | 没拿**主手** TNT；或没有 `missile.use` 权限 |
| 半主动弹发射不了 | 准星 10° 内没有合法目标（或视线被挡）—— 先看向目标再右键 |
| 锁不上人 | 超过 128 格 / 不在准星 10° 内 / 视线被方块挡住 / 对方是旁观者 / 是生物但模式是 `player`（或反之） |
| 导弹中途拐弯、追别人去了 | 对方（或第三方）拿着干扰物：红外被烈焰棒拉走、半主动 / 主动被铁粒干扰 |
| 导弹直飞不追 | 用的是 `semiLOS`（本来就是手动驾束，要你自己用准星带）；或是目标已死 / 前方锥角内无目标 |
| 导弹没直接命中也炸了 | 红外 / 半主动 / 主动都有 **3 格近炸引信**（semiLOS 例外，只在直接命中时爆炸） |
| 自己被炸伤 / 地形被炸 | 爆炸会伤及自身，发射后别贴脸；地形破坏由服务器配置 `explosion.break-blocks` 决定 |
| 完全没有告警 | 背包里要有**指南针**；另外红外与 semiLOS 本来就不触发 RWR |
| 提示文案是英文 | 服务器把 `language` 设为 `en_us` 了，可让服主切回 `zh_cn` |
| 动作栏/告警条突然消失 | 主手换掉了 TNT（导引头关闭）；或威胁解除（RWR 静默）；或你自己关掉了导弹开关（`/missile off`） |

## 9. 十条实用技巧

1. **偷袭用红外**：不触发 RWR，从 6 点钟方向发射对方毫无提示。
2. **正面冲突用主动**：速度快、会打提前量、抗铁粒最好。
3. **对方举烈焰棒克制你的红外时，换 semiLOS** —— 它免疫全部干扰物。
4. **半主动可以中途换目标**：准星移到另一个人身上，导弹会跟着改锁，适合打乱阵型。
5. **别忘了这是“视线”武器**：开导引头时目标必须在准星锥内且**没被方块挡住**。
6. **主动弹打逃跑的人是直线最优**：逃跑时**变向**比加速更保命。
7. **导弹擦边也会炸**（3 格引信），躲的时候要留出余量。
8. **听到“敌跟踪”就断视线**：半主动的照射需要视线，躲进掩体就能让它直飞。
9. **听到“敌导弹”马上抛干扰物**：烈焰棒克红外、铁粒克半主动 / 主动，且**要让导弹在你前方**（朝你飞来）才生效。
10. **创造模式可以放心试弹**：不消耗 TNT；单发最长飞 30 秒，最多同时 64 发。
